# info_aggr
an information aggregator with a social media style feed and diverse plugins to track types of data

An asynchronous aggregation tool for monitoring data and sending updates.

## Features
- Flask backend
- React frontend with Tailwind CSS
- Async data fetching and notification system

## Setup
1. Run `deploy.sh` to initialize the project.
2. Start the backend and frontend services.
3. Visit `http://localhost:3000` to see the frontend.
